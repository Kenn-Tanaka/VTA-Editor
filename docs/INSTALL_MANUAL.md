# Variation Tree Analysis Editor ＆ LLM Gateway パッケージ
## インストール・運用マニュアル (Installation & User Manual)

本パッケージは、**バリエーションツリー分析エディタ（Variation Tree Analysis Editor）**、および安全・セキュアにLLM推論を中継する**Lightweight LLM Gateway**と各種管理ツールを同梱した統合配布パッケージです。

---

## 1. パッケージ同梱内容

| ファイル / フォルダ | 種別 | 説明 |
| :--- | :--- | :--- |
| `start.bat` | 実行スクリプト | **ワンクリック起動バッチ**（GatewayとWebエディタを同時に起動してブラウザを開きます） |
| `vta-starter.exe` | 実行プログラム | **ゼロ依存・ネイティブ起動サーバー**（Node.js不要でGatewayとWebエディタを一括起動） |
| `credential-manager.bat` | 実行スクリプト | APIキー管理ツールを起動するランチャー |
| `test-gateway.bat` | 実行スクリプト | LLM Gatewayとの通信テストを実行するCLIランチャー |
| `llm-gateway.exe` | 実行プログラム | 軽量・高速なローカルLLMリバースプロキシ（C++完全静的リンク実装） |
| `llm-gateway-credential-manager.exe` | 実行プログラム | Windows資格情報マネージャーと連携した安全なAPIキー登録・管理GUI（静的リンク） |
| `llm_test.exe` | 実行プログラム | LLM Gatewayの健全性とモデル応答を検証するテストCLI（静的リンク） |
| `gateway.json` / `tools/llm-gateway/config/gateway.json` | 設定ファイル | LLM Gatewayのポート・CORS・プロバイダ設定 |
| `dist/` | Webアセット | 本番ビルド済みのSPA（HTML/CSS/JSベクター描画エンジン） |
| `AGENTS.md` | 設計仕様書 | VTA規約、アーキテクチャ方針、静的リンクおよび配布パッケージ規則 |

## 2. 動作要件（前提環境）

- **OS**: Windows 10 / 11 (64-bit)
- **Node.js**: **インストール不要（完全スタンドアロン実行可能）**
  - ネイティブC++製ランチャー `vta-starter.exe` により、Node.jsやnpmのインストールなしで即使えます。
- **Webブラウザ**: Google Chrome, Microsoft Edge, Firefox, Safari（最新版）
- **LLM利用環境**:
  - **ローカルLLM**: LM Studio（`http://127.0.0.1:1234` または Tailscale IP）や Ollama（`http://127.0.0.1:11434`）が動作していれば、APIキーなしで完全ローカル推論が可能です。
  - **クラウドLLM**: OpenRouter, OpenAI, Anthropic 等のAPIキーを利用することも可能です。
  - ※オフライン単体での図編集・手動作成のみであればLLM不要で動作します。

---

## 3. 初期セットアップ手順

### ステップ1: パッケージ（zip）の展開
ダウンロードした `vta-analysis-package.zip` を任意のフォルダ（例: `C:\Tools\VTA`）に解凍・展開します。

### ステップ2: LLM APIキーの登録（クラウド利用時のみ）
1. `credential-manager.bat`（または `llm-gateway-credential-manager.exe`）をダブルクリックして起動します。
2. 対象のプロバイダ（例: **OpenRouter**）を選択し、お持ちの API キー（`sk-or-v1-...`）を入力して「保存」をクリックします。
3. APIキーは平文ファイルではなく、**Windowsのセキュアな資格情報マネージャー（DPAPI暗号化）**に安全に保管されます。
※LM StudioやOllamaなどのローカルLLMのみを利用する場合は本ステップはスキップできます。

---

## 4. アプリケーションの起動方法

### 最も簡単な方法（推奨）
本フォルダ内の **`start.bat`**（または **`vta-starter.exe`**）をダブルクリックします。

自動的に以下の処理が行われます：
1. `llm-gateway.exe`（推論Gateway）がポート `8765` で自動起動
2. 内蔵の軽量Webサーバーがポート `5173` で起動
3. デフォルトのWebブラウザが自動的に開き、VTAエディタ画面が表示されます

---

## 5. LLM Gateway 接続確認テスト

Gatewayが正常に応答しているか確認したい場合、**`test-gateway.bat`** をダブルクリックして実行します。
正常に接続できている場合、利用可能なモデル一覧（`openrouter/anthropic/claude-3.7-sonnet`, `openrouter/google/gemini-2.0-flash-001` など）が出力されます。

## 6. Variation Tree Analysis Editor の主な操作方法

### ① 事故・トラブルシナリオの入力 / ファイル読込
- **直接入力**: 左側パネルの「シナリオ入力」欄に事故テキストを貼り付けます。
- **ファイル取込**: 「ファイル読込」ボタンから `.txt`, `.md`, `.docx` (Word), `.pdf`, `.xlsx` (Excel) を直接選択すると、自動でテキスト抽出されます。
- **サンプル事例**: 右上のサンプル切り替えから「衛星設計変更」「医療機器」「プラント作業」等の標準事例をワンクリックで読み込めます。

### ② VTA構造化データの自動生成（AI推論）
- 「⚡ VTA構造抽出を実行」をクリックすると、LLMが事故要因を解析し、時系列下から上（BT形式）のスイムレーンツリー図を自動構築します。
- 推論が長時間に及ぶ場合や中止したい場合は、進捗オーバーレイの「**処理を中断**」ボタンで即座にキャンセルできます。

### ③ 図上の編集・対策（排除ノード・ブレイク）の付与
- **排除ノード（○印）**: 変動要因カードの右上「○印」ボタンをクリックして対策を付与。
- **ブレイク（遮断）**: エッジ（矢印）上の鋏アイコンをクリックすると `BREAK` バッジが付与され、悪影響の伝播を遮断。
- **情報伝達矢印**: エッジをクリックして一方向（`──▶`）と相互確認（`◀──▶`）を切り替え。
- **カードの追加・編集**: ダブルクリックで詳細編集、またはツールバーの「＋ カード追加」から自由に追加可能。
- **時系列自動整列（BT自動整列）**: ツールバーの「BT自動整列」を押すと、全レーンを通して時系列の高さ（共通タイムスライス）が綺麗に整列します。

### ④ ノード補足説明・背景要因（ヒューマンファクタ分析）
- ツールバーの「**補足説明欄**」ボタンをクリックすると、右サイドパネルが展開。
- 全体総括および各ノードの背後要因（心理的要因、思い込み、組織的課題、設備制約）を加筆・編集できます。

### ⑤ 改善された業務フロー＆分析レポートの生成
- 対策（排除・ブレイク）と補足説明を元に、「✨ 改善業務フロー＆レポート生成」をクリックすると、LLMが事故を未然に防止する『改善された業務フロー』と論理的対策レポートを作成します。

### ⑥ 単一SVG出力 ＆ プロジェクト保存
- **SVG出力**:
  - ヘッダーまたはツールバーの「**SVG出力**」をクリック。
  - 出力設定ダイアログで「**空レーンを除外する（推奨）**」または「**空レーンを含める**」を選択し、補足説明欄を含めた単一SVGベクター画像（WordやPowerPointに貼り付け可能）をダウンロードできます。
- **プロジェクト保存・読込**:
  - 作業途中のデータは「プロジェクト保存」で1つの `.json` ファイルとしていつでも保存・復元が可能です。

## 7. トラブルシューティング（よくある質問）

### Q1. `llm-gateway.exe` の起動時にポートエラー（Port 8765 in use）が出る
- **原因**: 既に別の Gateway インスタンスが起動しています。
- **対応**: そのままでもWebエディタから通信可能です。再起動したい場合はタスクマネージャーから `llm-gateway.exe` を終了して再度 `start.bat` を実行してください。

### Q2. LLMの応答で「401 Unauthorized」や認証エラーが出る
- **対応**: 
  1. `credential-manager.bat` を起動し、OpenRouter等の有効なAPIキーが正しく登録されているかご確認ください。
  2. Webエディタ画面左パネルの「LLM設定」にある Gateway Token（任意設定）が一致しているかご確認ください。

### Q3. AI推論がタイムアウトしてしまう
- **対応**: 左パネル「LLM設定」から「タイムアウト（秒）」をデフォルトの 180秒 から 300秒 などに長めに設定してください。

### Q4. 凡例やボタンが隠れて見えない
- **対応**: ツールバー内の「ℹ️ 凡例」ボタンをクリックすると、凡例カードを開閉（トグル表示）できます。
